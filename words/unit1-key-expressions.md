# Unit 1 · Key Expressions（核心术语）

> 来源：教材 Unit 1 *College Life in the Age of AI* 词表照片，2026-10-18 整理。
> 这 8 个是「配对题」的词，考试时中英互译最容易混。

| # | 词 | 中文 | 备注 | 熟练 |
| --- | --- | --- | --- | --- |
| 1 | AI chatbots | 聊天机器人 | 复数常用，`an AI chatbot` 单数；chatbot 已是合成词 chat + bot | |
| 2 | AI-powered tutoring | AI 智能辅导 | 强调**由 AI 系统提供**的辅导，跟第 8 条区分开 | |
| 3 | artificial intelligence (AI) | 人工智能 | 全称只在这个正式场合写全，正文直接用 AI | |
| 4 | natural language processing | 自然语言处理 | 缩写 NLP，是 AI 的一个分支 | |
| 5 | data privacy | 数据隐私 | 不可数，不加 s | |
| 6 | learning efficiency | 学习效率 | efficiency 不可数；形容词 efficient | |
| 7 | machine learning | 机器学习 | 另一个分支，跟 NLP 并列 | |
| 8 | personalized tutoring | 个性化辅导 | 强调**量身定制**，不限定是 AI 做的 | |

## 易混：2 与 8

中文都译作「辅导」，英文侧重点完全不同：

- **AI-powered tutoring** → 谁来干的：AI 系统提供的
- **personalized tutoring** → 怎么干的：按你的水平量身定制的

配对题里这两个最容易对调。看到题目给中文「智能辅导」选 2，「个性化辅导」选 8。

## 实际用过（Unit 1 作文定稿）

2026-10-18 那篇 162 词的定稿里嵌了 3 个：

1. `an AI chatbot sorted through a stack of readings` → 第 1 条
2. `its AI-powered tutoring walked me through the idea three times` → 第 2 条
3. `Such tools greatly improve learning efficiency` → 第 6 条

剩下的 artificial intelligence / natural language processing / data privacy / machine learning / personalized tutoring 在作文里没用到，属于**能认不能用**，需要补练造句。
